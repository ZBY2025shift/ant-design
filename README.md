# 荆门静脉产业园智慧管理系统

## 项目简介

荆门静脉产业园智慧管理系统是一个基于 React + Next.js + Ant Design 开发的现代化管理系统，主要用于监测和管理静脉产业园的各项环境指标和运营数据。

## 功能特性

### 已实现功能

1. **三栏式布局**
   - 顶部栏：系统标题和用户信息
   - 左侧目录区：功能导航菜单
   - 右侧功能区：主要内容展示

2. **沉降监测模块**
   - 监测总览：最大沉降值、平均沉降值、预警点位数统计
   - 月度沉降监测折线图（含预警线和交点标记）
   - 数据管理：沉降监测数据的增删改查

3. **气体监测模块**
   - 填埋气监测：气体浓度、压力、流量、温度数据
   - 空气微站监测：SO2、NO2、CO、O3、PM2.5、PM10等11项指标
   - 超标预警：自动标识超标数据并显示警告
   - 数据管理：填埋气火炬监测和空气微站监测数据管理

4. **渗滤液监测模块**
   - 进水监测：进液总数、进液累计量
   - 排放监测：废水流量、PH、COD、氨氮
   - 趋势分析：COD、氨氮、PH 7天趋势图表

5. **响应式设计**
   - 支持桌面端、平板端、移动端适配
   - 断点：1200px、768px
   - 移动端侧边栏可折叠/展开

### 开发中功能

- 出入管理
- 视频监控
- 静脉产业园一期/二期
- 碳汇碳排放
- 系统设置
- 领导驾驶舱

## 技术栈

- **前端框架**：React 18 + Next.js 14
- **UI 组件库**：Ant Design 5.x
- **图表库**：ECharts + echarts-for-react
- **样式方案**：CSS Modules
- **开发语言**：TypeScript
- **日期处理**：Day.js

## 安装运行

### 环境要求

- Node.js >= 16.0.0
- npm >= 8.0.0

### 安装依赖

```bash
npm install
```

### 开发运行

```bash
npm run dev
```

访问 [http://localhost:3000](http://localhost:3000) 查看应用

### 构建生产版本

```bash
npm run build
npm start
```

## 开发说明

### 组件开发规范

1. 使用函数式组件和 Hooks
2. 使用 TypeScript 进行类型定义
3. 使用 CSS Modules 进行样式管理
4. 遵循 Ant Design 设计规范

### 数据格式规范

- 经纬度：保留小数点后三位
- 监测日期：YYYY-MM-DD HH:mm:ss
- 数值精度：根据实际需求保留合适小数位数

### 性能优化

- 使用 React.memo 优化组件渲染
- 图表数据懒加载
- 表格数据分页显示
- 响应式图片和组件
